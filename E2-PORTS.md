## Private event command

`opencode-event --protocol 1`; one JSON object, <=4096 bytes including whitespace.
Owned environment: `AGENT_NOTIFICATIONS_CONTROL_ROOT` is a canonical absolute
root; actual `os.Executable()` must be the registered command. No wire path,
ambient config, HOME discovery or Gate-only fallback authorizes an effect.
An owned stdin reader is closed and joined on cancellation. The original 20s
entry budget starts before argv/decode/config/locks. Independent E0 continuous
sampling begins before input; sender deadlines only shorten the budget.

Exact outer keys (all required): `protocol` (integer 1), `origin` (64 lowercase
hex), `event` (unchanged neutral version1 object), `provenance` (below).
Every object is closed; duplicate keys, aliases, unknown keys, nulls, missing
required keys, trailing frames, depth>8 or >96 total entries reject.

`event` keys: required `version`, `kind`, `sessionID`, `turnID`, `rootSession`,
`provenance`; completion additionally requires `messageID`; attention additionally
requires `requestID`. Other optional neutral keys `messageID`, `requestID`,
`nativeType` may only have the values permitted by the actual SDK decoder;
unsupported/unknown facts cannot authorize. Root must be true.
Its original D `provenance` requires `generation`, `observationID`, `nativeTime`,
`timeBasis`. `nativeEventID` and `nativeMessageID` are the only optional keys;
V2 requires nativeEventID; V1 error requires nativeMessageID. NativeTime is
an exact positive JSON integer <=9007199254740991 AND <=MaxInt64/1000000;
conversion to epoch ns is checked. ObservationID is opaque and never parsed.
V1 completion uses assistant_completed; V1 attention/error uses
assistant_created_lower_bound; V2 uses envelope_created. Completion Terminal is
neutral messageID (also for V2). Error Terminal is original nativeMessageID/V1
or nativeEventID/V2, with E1 v1_final_message/v2_terminal_event typed binding.
Session=sessionID, Execution=turnID, attention Request=requestID.

Outer `provenance` exact required keys:
`sourceEpoch`, `epochStartedTickNS`, `policyID`, `fence`, `anchor`,
`ingressTickNS`, `spawnTickNS`, `deadlineTickNS`, `calibration`.
All *NS values are canonical unsigned decimal **strings**, <=MaxInt64, including
zero written "0". SourceEpoch is nonempty printable ASCII <=128 bytes, separate
from stable fence. PolicyID and calibrationID must equal immutable trusted
selection; neither the frame nor config selects policy or expands tolerance.
Fence is exactly E1 TimePolicy.Fence: uint32 big-endian UTF-8 length-prefixed
AN/OpenCode/clock-policy/v1, boot, domain, RawKind, ProfileID, then int64 BE R,T.

`anchor` exact required keys: `boot`, `domain`, `rawKind`, `monoLoNS`,
`monoHiNS`, `wallNS`, `readUncertaintyNS`. Boot is canonical nonzero lowercase
UUID; domain and raw kind are exactly E0's closed native coordinate (Linux
linux-time:<dev>:<ino>, Darwin darwin-kernel, Windows windows-kernel).
0<=hi-lo<=100ms; read uncertainty = hi-lo+3ms and <=selected native R<=103ms.
WallNS must be positive. E1 TickNS=lo, Kind=continuous, UncertaintyNS=complete T.

`calibration` exact required keys: `calibrationID`, `sourceEpoch`,
`sourceLoNS`, `sourceHiNS`, `nativeLoNS`, `nativeHiNS`, `errorNS`.
ID and source epoch must match selection/outer provenance. The native interval
is the original anchor bracket; source bracket is ordered. The independently
qualified calibration error must equal trusted selection's TranslationBoundNS;
2R + errorNS <= complete T <=2s. No default T or source-rate grant exists.
Original lower anchors obey epochStart<=anchor.lo<=ingress<=spawn<deadline;
deadline-spawn<=20s; E1 enforces conservative age/queue/continuity bounds using T.
The trusted selection callback binds native generation and calibration to the
approved packaged source/clock cell. Current real selection is unverified.

## Runtime profile helper and inner ownership

Exact command: `opencode-runtime-profile --protocol 1`. One original <=10s
operation, signal.NotifyContext TERM/interrupt propagated to the synchronous
shared ProbeOpenCodeTarget (Cmd.Run/Wait, bounded streams, private cwd,
explicit PATH= and only --version). No PATH discovery/auth/config/HOME scan.
Owned stdin is cancellable and joined; input <=4096 bytes, closed depth<=8,
entries<=96. Input exact required keys: `protocol` integer1,
`hostExecutable`, `origin`, `controlRoot`, `nativePID` positive integer,
`entry` exactly `serve`, `publicExecPath`. Paths are canonical absolute and
hostExecutable=publicExecPath. Each field must equal separately captured owned
environment: AGENT_NOTIFICATIONS_HOST_EXECUTABLE, AGENT_NOTIFICATIONS_ORIGIN,
AGENT_NOTIFICATIONS_CONTROL_ROOT, AGENT_NOTIFICATIONS_NATIVE_PID,
AGENT_NOTIFICATIONS_HOST_ENTRY, AGENT_NOTIFICATIONS_PUBLIC_EXEC_PATH.
Environment is private descriptor transport, never observer authority by itself.
Linux live binding verifies PID kernel executable dev/inode/hash against target,
checks actual serve argv, and rechecks after probe. Other OS bindings currently
fail closed. Official copied image/entry/platform authority must additionally be
proved by the shared observer descriptor; version thresholds never grant it.

Exact successful transport receipt (newline; <=1024 bytes):
{"protocol":1,"semantic":"unverified","generation":"none","resourceClosure":"reaped_or_not_started"}
Keys always present, no extra keys. Closed semantic values `eligible`, `unverified`;
generation `none`, `v1`, `v2` (`eligible` requires v1/v2; unverified requires none).
ResourceClosure has only `reaped_or_not_started`. It is emitted only after actual
synchronous shared probe return or proof that probe was never invoked. Semantic
failure may still prove closure; exit0 means valid transport, not qualification.
Nonzero exit, missing/truncated/overflow/unknown receipt or forced KILL has no
inner proof. No paths, IDs, versions, stdout/stderr or error text in receipt.
Shared Resolve is called once after a probe; generic capability support alone
cannot grant observer eligibility. The composition callback receives immutable
shared Profile and verified live descriptor; empty real callback denies.

Future JS owner reserves runtime profile weight2 in the SAME max4 registry as
clock/event weight1; release only after actual outer close AND valid inner proof.
Uncertain closure retains weight2 and disables fresh handoffs. No second pool,
PID-scan repair or re-probe substitutes. JS registry/producer/bundle changes,
shared descriptor integration, immutable total T/native source qualification and
