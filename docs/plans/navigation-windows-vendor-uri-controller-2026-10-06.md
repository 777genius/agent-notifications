The controller reuses the bounded official download, signtool `/pa /all`, full
archive/probe hashes and collected SDK metadata. Before effects it requires the
exact OpenAI.Codex 26.930.7945.0 ARM64 publisher/family/fullName. This mode skips

absence of PackageDependency. It does not claim the earlier metadata run passed.

Exclusive custody, actual current-user absence, one collected Add success and
matching completion proofs precede a fresh installed-family read. One targeted
thread query precedes one targeted thread launch; its synthetic URI uses the fresh
TEST root UUID. All accepted reports bind child PID, nonce, family and fullName.
The launch's own pre-query is also checked. There is no settings/default fallback.
Mode invocation and actual API entry are separate observations: install/launch
attempt flags stay null until a correlated terminal report proves entry or refusal.
No-effect refusal does not prove current package absence. Package/hand-off/removal
state stays unknown during an unresolved effect and requires actual readback/results.

Cleanup invokes one Remove only after known Add success, collection of all invoked
actors and known later effect outcomes. Missing/partial/timeout/unknown launch or
install evidence blocks guessed removal and remains failed. Known declined launch
can remove the owned package but remains failed. Remove must complete successfully
and report current-user family absence. This is not all-process quiescence.

Native custody calls have a 165-second outer bound around the helper's cooperative
150-second budget. Each phase's partial stdout/stderr and available reports remain
in the final evidence. Both inputs are rehashed independently in finalization.
Uploaded evidence excludes the MSIX and prior ZIP; only small JSON/proofs/XML and
the explicitly compiled TEST probe are eligible.

Success means package-selected handoff acceptance and verified package removal.
Toast/cold callback, selected process/window, authenticated chat, target confirmation
and navigation qualification remain false. No native result is asserted here.
