# Security policy

## Reporting a vulnerability

Report suspected security vulnerabilities privately to the maintainer at
[quantjumppro@gmail.com](mailto:quantjumppro@gmail.com).
Please do not disclose vulnerability details in a public GitHub issue or pull
request before the maintainer has had an opportunity to investigate.

Include the affected version, operating system, installation method, steps to
reproduce, and the potential impact. Share a minimal proof of concept when
possible, and remove credentials, tokens, and other sensitive data from reports.

The maintainer will assess reports and coordinate fixes and disclosure with the
reporter. This project does not promise a response or remediation deadline or
offer a bug bounty.

## Versions

Use the latest stable release. Security fixes are generally delivered in a new
release; older versions do not have a separate security maintenance commitment.
